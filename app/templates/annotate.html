    Keys

    {# is the HTML element for a keyboard key; CSS makes it look like a keycap. #}
    • Click add a vertex
    • Enter or double-click close the polygon
    • Esc cancel the shape in progress
    • Click a finished polygon to select it
    • Drag a white handle to move a vertex
    • Click an edge of the selected polygon to insert a vertex
    • Delete or Backspace remove the selected polygon (or one vertex if a handle is selected)
    • Shift while moving: slower vertex / pointer (keeps tracking if you leave the image; the system cursor is unchanged)

    Coordinates are saved in native image pixels (COCO JSON).
