Reproduce a microscopist's expertise

{# home-lead is the manifesto: larger and darker than the paragraph below (see style.css). #}

This is not a tool for pointing at interesting objects. A deep-learning model copies how a microscopist outlines the same features, so the result stays reproducible. From image to image, and from one operator to another.

The simple idea is to automate the count. Instance masks go further than a tally: every object is a contour you can export (COCO JSON and mask files) and reuse later for sizes, densities, or any analysis you already run elsewhere. Currently, the post-processing is up to you. It could be possible to extend the project to include some.

Workspace

Instance segmentation

Annotate TEM images with polygons, train a model on your classes, then run inference with a colour overlay, mask files, and COCO JSON.

Compute

Training needs a GPU. If this computer has none, train on a GPU workstation (Thomas, Camilo, another CUDA machine).

Inference should run on CPU. Expect roughly a second to a minute per image, depending on its dimensions.
